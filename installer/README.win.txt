  EDGE CONTROL CENTER v1.0.0 "IGNITION"
  Модифицированный софт для ARDOR GAMING Edge 3327 (750 Вт · 16 ГБ ·
  GPT/UEFI · Windows + Linux · мышь PAW-3327)
════════════════════════════════════════════════════════════════════

БЫСТРЫЙ СТАРТ
─────────────────────────────────────────────────────────────────────
1. Распакуй ZIP ЦЕЛИКОМ в любую папку (например, D:\EdgeControlCenter).
2. Запусти EdgeControlCenter.exe — откроется консоль и браузер
   на http://127.0.0.1:3327
3. Панель «Admin» → пользователь hasberd, пароль по умолчанию:
   ardor-3327  →  СРАЗУ СМЕНИ его (кнопка «Rotate passphrase»).
4. Готово. Все модули слева: Device, Power, Memory, Storage, Network,
   Bridge, Stability, AI Studio, Thermal, Admin.

ЧТО ЭТО ДАЁТ
─────────────────────────────────────────────────────────────────────
• Unlock-банк: включает скрытые модули, которые ARDOR зашила в
  OemDrv.exe, но выключила в Cfg.ini (Gun-баллистика, отчёт
  диагностики, LOD, angle-snap, шторка сенсора).
• Полный редактор конфига мыши (DPI-ступени + цвета, дебаунс DR/DM,
  LOD) с экспортом Cfg.ini, совместимым со СТОКЫМ приложением:
  панель Device → «Export Cfg.ini» → положи файл в папку stock-OemDrv
  (оригинал предварительно сохрани).
• Телеметрия платформы: БП 750 Вт (стена/КПД/рейки/PL1-PL2), память
  16 ГБ (XMP/EXPO, тюнинг vm), GPT/UEFI-хранилище, сеть (ping/DNS/
  DPI-lite/QoS), стабильность (анализ BSOD + плейбуки), ИИ-студия
  (полностью локальная генерация через ComfyUI/A1111), предиктивная
  термалка. Всё честно помечено LIVE / MODEL / SIM.

ФАЙЛЫ
─────────────────────────────────────────────────────────────────────
  EdgeControlCenter.exe   — всё-в-одном (Node 22.22.3 внутри)
  Cfg.ini                 — стоковый файл (исходник конфиг-плейна)
  app\                    — сервер и интерфейс
  app\data\               — создаётся при работе (аудит, галерея)
  Start-ECC.cmd           — запасной запуск через системный Node.js

ПОЛЕЗНОЕ
─────────────────────────────────────────────────────────────────────
• SmartScreen при первом запуске: «Подробнее → Выполнить в любом
  случае» (EXE не подписан сертификатом).
• Брандмауэр спросит про порт 3327/UDP 33270 — это локальный дашборд
  и мост EBP между Windows и Linux. Разреши в частных сетях.
• Переменные окружения: PORT (порт, по умолч. 3327),
  ECC_DATA (куда писать данные), ECC_NO_BROWSER=1 (не открывать
  браузер — удобно для автозапуска).
• Мост со второй ОС: на Linux-стороне
  python3 agent/edge-agent.py pair <этот-ПК> 3327
• Если EXE заблокирован политиками — используй Start-ECC.cmd
  (нужен установленный Node.js ≥ 18).

УДАЛЕНИЕ: просто удали папку. Систему и стоковый ARDOR софт
Edge Control Center не трогает: все правки — в копии Cfg.ini.
